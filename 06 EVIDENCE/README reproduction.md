# Воспроизведение локальных проверок

Проверки выполнены 23.10.2026 в локальной рабочей области. Оригинальные документы не передаются в этом архиве. Их владелец предоставляет копии; E01-E13 и L01-L04 идентифицируются по P01 source manifest.json.

1. Python 3.12, openpyxl 3.1.5, PyYAML 6.0.3, beautifulsoup4. Команда: `python "reproduce checks.py" --sources SOURCE_DIR --out result.json --helm HELM_EXE`. Helm необязателен; использована версия 3.19.0. Скрипт не запускает приложение и не выводит значения паролей.
2. Для собственного пересчёта E03 на Windows с Excel: `pwsh -File "P05 excel recalculate.ps1" -SourceModel MODEL.xlsx -OutputDirectory NEW_DIRECTORY`. Скрипт работает с копией, отключает макросы и обновление внешних ссылок, меняет Допущения!F19 на 1/2/3 и возвращает к 1. Сверить сохранённые caches и контрольные строки. Подтверждённый исходный файл должен соответствовать SHA-256 E03.
3. P03 содержит точные команды Helm, exit codes и обезличенный вывод. Негативный ввод словаря env ошибочен; корректный массив EnvVar успешно рендерится. Полные manifests с автоматически сгенерированными секретами не сохранялись в инвесторский комплект.
4. P04 показывает арифметику из представленных документов. Пересчёт не удостоверяет истинность первичных данных. Параметры e, b, SLO и нормы занятости в программах испытаний - предложения для согласования.
5. P00 фиксирует время записи результатов по файловым меткам, инструменты, ограничения и незаполненные сведения о принятии ответственным экспертом в документе 17. Эти записи не доказывают личное участие неизвестных аудиторов.

Проверка файлов: все 23 DOCX открыты в Microsoft Word 16.0, оглавления и поля обновлены, выполнен экспорт в контрольные PDF и PNG. Штатный render_docx.py не запустился из-за отсутствия LibreOffice; использован установленный Word. Контрольные изображения сформированы для всех страниц; выбранные страницы проверены визуально; машинно проверены границы текста и ошибки полей. Полная ручная вычитка каждой страницы кадровых сканов не заявляется. Контрольные PDF/PNG хранятся в рабочей области и не входят в ZIP. Восемь листов двух XLSX просмотрены через рендеринг Artifact Tool.

Подлинность ЭЦП, титул на код, фактические платежи, функциональность, нагрузка и кибербезопасность продукта требуют дальнейших процедур документа 20. Не использовать проект как подписанное заключение SKILL PRO.

Обновление оформления: во всех 23 DOCX и двух XLSX закреплены Times New Roman и чёрный цвет текста; длинные тире заменены на ASCII-дефис. Проверка реальных PDF-шрифтов и цвета текста сохранена в Q02. Реквизиты SKILL PRO внесены по публичной карточке A01; банковские реквизиты и основание полномочий требуют отдельных документов.
